# Airtable-projet
## Getting Started

Dans le .env du dossier /portfolio ajouter les Key
```bash
NEXT_PUBLIC_AIRTABLE_API_KEY=
NEXT_PUBLIC_AIRTABLE_BASE_ID=
NEXTAUTH_SECRET=
````

On utilise docker

```bash
docker-compose up -d

Ouvrir http://localhost:3000
````
